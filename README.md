# Sales & Inventory Data Analysis Project (SQL Case Study)

## Overview
This project is a real-world style SQL data analysis case study focused on sales, customers, products, and inventory. It demonstrates how raw business data can be transformed into actionable insights using SQL.

The analysis covers performance tracking, customer behavior, and inventory optimization using advanced SQL techniques.
---

## Business Objectives
- Understand customer purchasing behavior
- Identify top-performing products and customers
- Track sales performance over time
- Detect low-stock and high-demand products
- Improve decision-making through data-driven insights
---

## Tools & Technologies
- PostgreSQL (SQL)
- DBeaver / SQL Editor
- Git & GitHub
- Excel/CSV (for raw data handling)
---

## SQL Techniques Used
This project demonstrates both basic and advanced SQL concepts:
- INNER JOIN, LEFT JOIN
- GROUP BY, HAVING, ORDER BY
- Aggregations (SUM, COUNT, AVG)
- Window Functions (RANK, LAG)
- Common Table Expressions (CTEs)
- Stored Procedures
- Indexing for query optimization
- Data filtering and transformation
---

## Key Business Insights

- Identified top customers based on total spending
- Ranked best-selling products by revenue and quantity
- Detected products with low stock levels (inventory risk)
- Analyzed sales trends and performance patterns
- Improved query efficiency using indexing strategies
---

## Key Learning Outcomes
- How to structure real-world SQL analysis projects
- How to clean and transform raw business data
- How to use advanced SQL features for analytics
- How to translate data into business insights
